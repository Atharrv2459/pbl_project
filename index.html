HR Solutions- Smart HRMS with Geoattendance & Recruitment Platform

"A secure, role-based HR management system that automates attendance and leave workflows, validates attendance with geolocation, supports shift & schedule management, and adds a complete recruitment pipeline (jobs → applications → screening → interviews → offers), with payroll tools and AI-assisted resume analysis."

Problem Statement

Traditional HR operations suffer from manual attendance errors, weak verification (buddy punching), fragmented tools for leave/shift approvals, and slow recruitment tracking. Organizations need a unified, secure platform that verifies attendance with location checks, supports employee-manager approval workflows, centralizes recruitment & offer management, and provides analytics for HR decisions.

Literature Review

Manual registers, spreadsheets, and basic biometric systems lack end-to-end workflows, real-time approvals, audit trails, and integrated hiring + HR operations.

Innovation

A single HRMS with role-based dashboards (Employee / Manager / HR), geolocation-verified attendance, structured shift scheduling, leave + manual correction approvals, and a recruitment pipeline with interviews and offer letters—plus AI resume analysis to speed up shortlisting.

Key Modules

Attendance + Geolocation

Punch-in/out with location verification (authorized area). Logs attendance history, break tracking, and real-time visibility for HR/Managers.

Shift & Scheduling

Shift preferences, shift scheduling, location assignment, and department mapping to organize workforce planning.

Leave + Approvals

Leave requests and approvals with manager workflow. Manual attendance entry/correction requests with audit-friendly tracking.

HR Panel

HR dashboard to manage employees, departments, locations, policies, and organization-wide insights.

Recruitment Pipeline

Job postings, applications, screening questions, interview scheduling (panelists + feedback), and offer letter management with status tracking.

Payroll Tools

Salary structures, payroll processing support, and HR-driven salary/compensation workflows (as per system modules).

AI Resume Analysis (Gemini)

AI-assisted resume vs job-requirements matching for faster screening, improved consistency, and better shortlisting insights.

System Methodology

Data Layer

PostgreSQL stores employees, attendance logs, breaks, leaves, shifts, locations, recruitment pipeline entities, and payroll metadata.

Architecture

React + Tailwind (UI), Node.js + Express (API), PostgreSQL (DB), JWT auth, and WebAuthn device-bound verification. Geolocation is used for attendance validation, and the HR panel manages end-to-end workflows.

1.Role-based login (Employee / Manager / HR) via JWT.
2.Attendance actions validated with location checks.
3.Leave + manual corrections go through approval workflow.
4.Recruitment pipeline tracks applications → interviews → offers.
5.Dashboards provide analytics + audit-friendly logs.
